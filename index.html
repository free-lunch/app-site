ODF Labs is an AI-native indie app studio. One engineer and a team of Claude-powered agents design, build, release, and monitor mobile apps for a global audience.

How we build

Idea → app in days

Specs, wireframes, and code are drafted with Claude and reviewed by a human before every release.

Agents run operations

Store metrics, ad revenue, analytics events, and release checks are collected daily by Claude Code agents.

Ship, measure, repeat

Many small experiments. Keep what users love, learn from the rest.

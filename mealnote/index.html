식단플래너 개인정보처리방침

시행일: 2026년 4월 8일 (최종 개정: 2026년 5월 31일)

ODF(이하 "개발자")는 식단플래너(이하 "앱") 이용자의 개인정보를 소중히 여기며, 관련 법령에 따라 아래와 같이 개인정보처리방침을 수립하여 공개합니다.

1. 수집하는 개인정보

식단플래너는 이용자의 식단·재료·레시피 등 직접 입력한 내용을 외부 서버로 전송하지 않으며, 해당 데이터는 모두 사용자의 기기 내에만 저장됩니다.

다만 앱 품질 개선을 위해 익명의 사용 통계·진단·사용성 정보가 수집됩니다(아래 4항 참조).

앱 내에서 사용자가 직접 입력하는 정보(기기 내 저장):

  • 식단 계획 (아침, 점심, 저녁 메뉴)
  • 재료 목록 (구매, 보유)
  • 레시피 정보 (제목, 재료, 조리 순서, 태그)
  • 앱 설정 (테마, 글자 크기, 시작 화면 등)

2. 개인정보의 저장 및 보관

모든 데이터는 사용자의 기기(로컬 저장소)에만 저장되며, 개발자의 서버나 클라우드에 전송되지 않습니다. 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.

3. 개인정보의 제3자 제공

식단플래너는 사용자의 개인정보를 제3자에게 제공하지 않습니다.

4. 광고 및 분석 도구

식단플래너는 서비스 운영과 품질 개선을 위해 아래 제3자 도구를 사용합니다. 이 과정에서 식단·재료·레시피 등 이용자가 입력한 내용 자체는 전송되지 않습니다.

  • Google AdMob (광고) — 광고 제공을 위해 기기 식별자(광고 ID) 등을 수집할 수 있습니다.
  • Firebase Analytics (사용 통계) — 어떤 기능이 사용되는지 등 익명의 사용 통계를 수집합니다.
  • Firebase Crashlytics (오류 진단) — 앱 비정상 종료 시 진단 정보를 수집합니다.
  • Microsoft Clarity (사용성 분석) — 화면 터치·이동 등 익명의 사용성 정보를 수집하여 사용 흐름을 분석합니다. 입력 필드의 내용은 자동으로 가려진(마스킹) 상태로 처리됩니다.

각 도구의 데이터 처리는 해당 제공자의 개인정보처리방침을 따릅니다.

  • Google 개인정보처리방침
  • Microsoft 개인정보처리방침

5. 보안

식단플래너의 모든 데이터는 사용자의 기기에만 저장되므로, 기기 자체의 보안(화면 잠금 등)에 의해 보호됩니다.

6. 이용자의 권리

사용자는 언제든지 앱 내에서 자신의 데이터를 확인, 수정, 삭제할 수 있습니다. 앱을 삭제하면 모든 데이터가 완전히 삭제됩니다.

7. 아동의 개인정보

식단플래너는 만 14세 미만의 아동을 대상으로 하지 않으며, 의도적으로 아동의 개인정보를 수집하지 않습니다.

8. 개인정보처리방침의 변경

본 방침이 변경되는 경우, 앱 업데이트 또는 이 페이지를 통해 공지합니다.
